# Changelog

## 0.8.0 - 2026-11-23

First release, the widget test utilities of `typed_router`.

- The widget test utilities of typed_router (`TypedRouterTester`,
  `PredictiveBackGesture`, `PlatformNavigationLog`) move here from
  `package:typed_router/testing.dart`. Add this package to
  `dev_dependencies` and import
  `package:typed_router_test/typed_router_test.dart`.

- `PredictiveBackGesture` and `PlatformNavigationLog` are no longer
  `final`.
